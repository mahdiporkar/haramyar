# راهنمای استقرار و ورود مجموعهٔ عزالدین سلیم

**۱۷ اکتبر ۲۰۲۶:** فهرست و ابزار ورود آماده‌اند، اما هنوز هیچ PDF روی MinIO عملیاتی یا haramyar.com بارگذاری نشده است.

## موجودی

- ۴۸ PDF تحویل‌شده، شامل ۳ تکرار بایت‌به‌بایت؛ ۴۵ تألیف یکتا و ۶٬۷۵۴ صفحه.
- نگاشت نام فارسی/انگلیسی/عربی ۴۵ فایل در [فهرست CSV](salim-books.csv) مشخص است؛ هر فایلِ با نام انگلیسی ترجمهٔ انگلیسی محسوب نمی‌شود.
- شش کتاب دربارهٔ شهید موجودی PDF ندارند و نباید با تألیفات او یکسان شمرده شوند.
- [پیش‌نویس زندگی‌نامهٔ سه‌زبانه](salim-profile-draft.json) متن مبنای عربی، دو ترجمهٔ فارسی و انگلیسی و منابع را نگه می‌دارد.
- برای ۴۵ اثر عربی به ۹۰ ترجمهٔ کاملِ مستقل (۴۵ فارسی + ۴۵ انگلیسی) و کنترل انسانی جداگانه نیاز داریم؛ هنوز آماده نیستند.

## آزمون آفلاین بدون شبکه

```bash
node tools/martyrs-import-books.mjs --source-dir ../upload
node --test tests/unit/martyrs-import-books.test.mjs
```

این بررسی وجود همهٔ منابع، امضای PDF، حجم کمتر از ۳۰ MiB، هش SHA-256 و یکتا بودن بایت‌ها را کنترل می‌کند؛ هیچ داده‌ای به سایت نمی‌فرستد.

## آماده‌سازی محیط واقعی

1. پس از بررسی CI، تغییرات شاخهٔ feat/minio-multilingual-books را در محیط آزمایشی CapRover مستقر کنید.
2. نخست MinIO اختصاصی با نام haramyar-books-storage و volume مستقل haramyar-books-data را راه‌اندازی و تست کنید. سپس martyrs-api با تنظیمات BOOKS_S3_* و migrationهای V2/V3 و frontendها را مستقر کنید. bucket خصوصی باقی بماند.
3. با حساب دارای نقش staff در تحریریه احراز هویت کنید. مقدار توکن یا نشست را **فقط در secret store / محیط محافظت‌شده** به متغیر HARAMYAR_EDITOR_TOKEN یا HARAMYAR_EDITOR_SESSION_COOKIE بدهید؛ در صورت نیاز HARAMYAR_EDITOR_CSRF. **هرگز رمز را در Git یا چت قرار ندهید.**
4. پذیرش توکن Bearer یا cookie توسط BFF در محیط واقعی باید آزموده شود. خطای 401/403 مانع مجوز است، نه چیزی برای دورزدن.

## ورود گروهی پروفایل و آثار عربی

```bash
node tools/martyrs-import-books.mjs --source-dir ../upload --apply --ensure-profile
```

این فرمان:

- پروفایل izz-al-din-salim را در صورت فقدان به صورت DRAFT ایجاد می‌کند؛ منبع زندگی‌نامه و پیش‌نویس دو زبان دیگر را در تحریریه ثبت می‌کند. عکس چهرهٔ شناسایی‌شده از گالری رسمی را بدون ارسال اعتبارنامه به سایت مرجع دریافت و، در صورت دسترسی و نبود تصویر قبلی، به رسانهٔ پیش‌نویس پروفایل می‌افزاید. اختلال سایت منبع مانع ورود کتاب‌ها نمی‌شود.
- هنگام اجرای مجدد، پروفایل و ترجمه‌های موجود را دستکاری نمی‌کند.
- برای هر عنوان تألیفی کتاب و ویرایش عربی DRAFT را ثبت می‌کند و فایل PDF را از API تحریریه به MinIO خصوصی منتقل می‌کند.
- فایل متصلِ موجود را بدون جایگزینی رد می‌کند؛ برابری SHA سمت سرور در API فعلی نمایش داده نمی‌شود، لذا باید جداگانه بررسی شود.
- **هیچ درخواست submit یا publish صادر نمی‌کند.**

برای پروفایل موجود می‌توان به جای --ensure-profile گزینهٔ --profile-id و UUID واقعی را فرستاد؛ این روش پروفایل یا ترجمه‌های زندگی‌نامه را ایجاد نمی‌کند.

## کنترل و انتشار

1. عنوان اصلی هر ۴۵ کتاب از صفحهٔ عنوان PDF بررسی و در صورت لزوم اصلاح شود؛ عکس‌های شهید از نظر هویت، اعتبار و مجوز کنترل شوند.
2. هر کتاب عربی و هر ترجمه را جداگانه از DRAFT به IN_REVIEW و سپس با تأیید بازبین دوم به PUBLISHED منتقل کنید.
3. متن و PDF کامل فارسی و انگلیسی را پس از ترجمه، مقابله و صفحه‌آرایی وارد کنید؛ پیش‌نویس صفحه‌های محدود جایگزین ترجمهٔ کامل نیست.
4. سه نسخهٔ زندگی‌نامه نیز باید مستقل تأیید شوند. پس از انتشار، نشانی‌های /martyr/izz-al-din-salim?lang=ar و lang=fa و lang=en و لینک دانلود PDFها را کنترل کنید.
